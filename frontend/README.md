# AptiSense Frontend

React 19 + TypeScript + Vite single-page app for AptiSense. See the [main README](../README.md) for the full project overview and setup.

```bash
cp .env.example .env   # VITE_API_URL points at the Express backend
npm install
npm run dev            # http://localhost:5173
npm run build          # type-check and production build
npm run lint
```
